# 🐾 Registro de Mascotas para Adopción

Este proyecto fue desarrollado como parte de la evaluación práctica.

La aplicación simula un sistema para administrar mascotas disponibles para adopción, permitiendo registrar nuevas mascotas, visualizarlas en una lista, cambiar su estado de adopción, eliminarlas, filtrarlas por estado y mostrar estadísticas generales.

Durante el desarrollo se aplicaron los principales conceptos vistos en clase, incluyendo:

- Componentes
- Props
- `useState`
- `useReducer`
- Context API
- Formularios controlados
- Renderizado de listas
- Renderizado condicional
- Manejo del estado global en React

El objetivo principal del proyecto es demostrar la correcta implementación de estos conceptos mediante una aplicación funcional, organizada y con una interfaz desarrollada completamente en React.
